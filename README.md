# solder

Solder is a beginner program where you make your first circuit board!! Plus, we'll give you a grant to order it + ship a kit components to you to assemble it :D

There is a tutorial to learn from scratch on the site. This program takes just around 5 hours to finish!

Start here: [solder.hackclub.com](https://solder.hackclub.com)
